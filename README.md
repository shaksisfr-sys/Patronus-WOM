# Тест на Патронуса — World of Magic

Русскоязычный одностраничный сайт для публикации на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через несколько минут сайт будет доступен по адресу вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Настройка

Весь сайт находится в одном файле `index.html`. Тексты вопросов, варианты ответов, архетипы и каталог Патронусов расположены в JavaScript внутри этого файла.

## Важно

Это авторский развлекательный тест, не научная диагностика и не официальный тест Wizarding World. В текущей версии используется локальный алгоритм сопоставления ответов и профилей. Перед широким запуском рекомендуется провести пробные прохождения и откалибровать распределение результатов на реальных ответах.
